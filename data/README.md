# Données

Les fichiers de données ne sont pas versionnés dans Git (voir `.gitignore`). Pour reproduire le projet :

1. Télécharger `csv-100k.7z` depuis la release **ready-to-use-data** du dépôt
   [sql-bi/Contoso-Data-Generator-V2-Data](https://github.com/sql-bi/Contoso-Data-Generator-V2-Data/releases/tag/ready-to-use-data).
2. Extraire l'archive dans `data/raw/`.

**Source :** Contoso Data Generator V2, SQLBI, licence MIT.
**Volume :** environ 100 000 commandes.
